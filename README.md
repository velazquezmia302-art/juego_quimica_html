# 🧪 LabSkills - Laboratorio de Soluciones Químicas

Una plataforma interactiva y educativa para practicar procedimientos de seguridad química y preparación de soluciones.

## 📚 Características

### 1. **Memorama SGA** 🃏
- Juego de memoria interactivo con pictogramas de seguridad
- Empareja símbolos de peligro con sus significados
- Ideal para aprender sobre clasificación de riesgos químicos
- Pictogramas incluidos:
  - 🔥 Inflamable
  - 💀 Tóxico Agudo
  - 🧪 Corrosivo
  - 💥 Explosivo

### 2. **Ordenar Pasos** 📋
- Arrastra y ordena los pasos del procedimiento correctamente
- Soporta tanto desktop (drag & drop) como móviles (touch)
- Procedimiento completo de preparación de soluciones:
  1. Cálculo de masa del soluto
  2. Pesaje en balanza analítica
  3. Disolución en vaso de precipitados
  4. Transferencia al matraz aforado
  5. Adición de agua destilada y aforo
  6. Homogeneización

## 🎮 Cómo Usar

1. Abre `index.html` en tu navegador
2. Selecciona una actividad en las pestañas
3. **Memorama**: Haz clic en las tarjetas para encontrar parejas
4. **Ordenar Pasos**: Arrastra los pasos para ordenarlos correctamente
5. Verifica tu respuesta con el botón "Verificar Procedimiento"
